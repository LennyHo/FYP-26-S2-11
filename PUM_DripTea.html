FYP-26-S2-11 — DripTea AI Chatbot

Preliminary User Manual (PUM)

1. Introduction

This Preliminary User Manual is written to help a first-time user get the DripTea AI Chatbot web application up and running. It covers the installation steps, configuration, and a walkthrough of the main pages so users can get to their first order without confusion.

1.1 What this manual covers

  • Initial installation on Windows and Mac (frontend + backend).
  • First-time configuration (environment variables and database setup).
  • Verifying the installation to confirm all services are connected.
  • A quick tour of the main pages and the AI chatbot widget.

1.2 What we assume about the readers

  • Basic familiarity with opening a terminal and running commands.
  • Readers know how to clone a project from GitHub and open it in VSCode.

1.3 Scope and Purpose

DripTea is a bubble tea ordering web application for a bubble tea shop in Singapore. Customers can chat with Avy, an AI chatbot, to get drink recommendations and place orders. This manual covers initial installation, configuration, and the main GUIs.

Don't want to install locally? The app is live at: https://driptea-ruby.vercel.app/

2. The Initial Installation Instructions

2.1 Prerequisites

System Requirements

  • Node.js v18 or later
  • npm v9 or later
  • A MongoDB Atlas account (or a local MongoDB instance)
  • A Groq API key — https://console.groq.com/keys
  • A Gemini API key — https://aistudio.google.com/apikey
  • Git (to clone the repository)

2.2 Backend Setup

Run these steps from the project root folder (FYP-26-S2-11/).

cd FYP-26-S2-11
npm install

Create a .env file in the project root and fill in your keys:

GROQ_API_KEY=your_groq_api_key_here
GEMINI_API_KEY=your_gemini_key_1,your_gemini_key_2
MONGODB_URI=mongodb+srv://<username>:<password>@<cluster>.mongodb.net/?appName=fyp-chatbot
MONGODB_DB_NAME=fyp-chatbot
MONGODB_AUTOCONNECT=true
PORT=5000
NODE_ENV=development
CHAT_LANGUAGE_MODE=english

Start the backend:

npm run dev

2.3 Frontend Setup

Run these steps from inside the view/ folder. Create a .env.local file inside view/:

DRIPTEA_API_BASE=http://localhost:5000
cd FYP-26-S2-11/view
npm install
npm run dev

Open http://localhost:3000 in your browser.

2.4 Verifying the Installation

After both servers are running, open the chatbot widget at http://localhost:3000 and type "Hello". Avy should reply. This confirms the frontend, backend, AI, and database are all connected correctly.

3. Key Features

3.1 User Roles

Customer — Browse the menu, chat with Avy for recommendations, customise drinks, manage cart and checkout.

Store Staff — Manage the drink menu, process incoming orders, and monitor inventory.

User Admin — Manage all user accounts and control access from the admin dashboard.

4. GUI Walkthrough — Customer

4.1 Landing Page

This is the first page users see when visiting DripTea. It shows the main banner, navigation links, and a floating Avy chatbot widget for users to start ordering or get recommendations immediately.

4.2 Login Page

Users enter their registered email address and password to log in to their account.

4.2.1 Login Page — Wrong Details

If the wrong email or password is entered, an error message is shown prompting the user to try again.

4.3 Register Page

New customers fill in their full name, email address, and password to create a DripTea account.

4.4 Recovery Page

Users who have forgotten their password can enter their registered email address to reset it and create a new password.

4.5 Profile Page

Customers can update their personal details, change their profile picture, and update their password from this page.

4.6 Menu Page

This page shows the full DripTea drink menu organised by category. Users can browse or filter drinks by category.

4.6.1 Drink Detail & Customisation Page

Clicking on a drink opens the detail page where users can customise their order by selecting size, ice level, sugar level, and toppings before adding it to the cart.

4.7 Cart Page

Users can review all the drinks they have added, including customisations and price, and either remove items or proceed to checkout.

4.8 Checkout Page

Users confirm and place their order from this page. Once submitted, the order is sent to store staff for processing.

4.9 Order History & Tracking

Customers can view past orders and track the current status of active orders. Users can also ask Avy directly in the chatbot for updates on their order.

AI Chatbot — Basic Features

4.10 AI Chatbot — Avy

Avy is the DripTea AI chatbot available as a floating widget on the website. When opened, Avy greets the user and is ready to take drink orders or answer questions.

4.10.1 Sending a Message

Users type a message in the text box and press Send. While Avy is processing, a typing indicator is shown. Chat history with timestamps is displayed in the window.

4.10.2 Quick Prompts

Pre-set shortcut buttons appear above the input box for common queries. Users can tap any prompt to send it instantly without typing, which is useful for first-time users.

4.10.3 Ordering Through the Chatbot

Avy guides users through the full ordering flow — from choosing a drink to selecting size, ice, sugar, and toppings. Once confirmed, users can view the cart or customise the order further directly from the chat.

4.10.4 Health & Dietary Assistance

Users can ask Avy health-related questions such as "What is the healthiest drink?" or "Which drinks are low in sugar?" and Avy will suggest suitable options from the menu.

4.10.5 Knowledge Information

Users can ask Avy about any drink ingredient or topping, for example "What is pearl?" Avy will explain what it is and how it pairs with drinks to help users make informed choices.

4.10.6 Searching Chat History

Users can click the search icon at the top of the chatbot to search through past messages by keyword.

AI Chatbot — Advanced Features

4.11 Image Recognition

Users can upload a drink photo, paste an image, or use their camera to send an image to Avy. Avy will analyse the image and respond, for example identifying the drink and suggesting similar items from the menu.

4.12 Speak & Microphone Mode

Users can click the microphone button to speak their order or question. A full-screen voice overlay is available for a hands-free conversation where Avy listens, processes, and reads its replies out loud.

4.13 Multilingual Support

Avy can detect the language a user is typing in and reply in the same language, allowing non-English speaking customers to use the chatbot comfortably.

4.14 Fallback Response

If Avy receives a message it cannot understand or that is outside its scope, it responds with a fallback message and guides the user back to drink-related topics.

5. GUI Walkthrough — Store Staff

5.1 Store Staff Login

Store staff log in using their registered email and password. Once logged in, they are brought to the Menu Management page.

5.2 Menu Management

This page shows all drinks on the menu with their category, price, and current status. Staff can toggle any drink between Active and Inactive to control what customers can order.

5.3 Add Drinks

Staff can add a new drink to the menu by filling in the drink name, category, price, description, tags, and status. The new drink appears on the menu once saved.

5.4 Dashboard

The Order Dashboard is where staff manage all incoming customer orders. It shows a live summary of open orders, orders being prepared, total inventory, and low stock alerts.

5.4.1 Order Queue Tab

This tab lists all incoming orders. Staff advance each order through the workflow by clicking "Start Preparing", "Mark Ready", and "Complete". The list refreshes automatically every 5 seconds.

5.4.2 Inventory Tab

Staff can view current stock levels and adjust quantities in real time using plus and minus buttons. Items running low are flagged with a warning badge.

5.5 Search

A search bar on both the Menu Management page and the Order Dashboard lets staff quickly find drinks or orders by name, category, or order details.

6. GUI Walkthrough — User Admin

6.1 User Admin Login

Admins log in using their registered email and password. Once logged in, they are brought to the User Admin Dashboard.

6.2 User Admin Dashboard

The dashboard gives an overview of all registered users, broken down by role (Customer, Store Staff, Admin) and account status. Suspended accounts are highlighted as an alert.

6.3 View User Account

Admins can click on any user to view their full account details including name, email, role, status, and account dates. Admins can also create new user accounts from this section.

6.4 Suspend User Account

Admins can suspend or reactivate any user account directly from the user table with a single click. Suspended accounts are visually flagged in the dashboard.

6.5 Search User Account

A search bar lets admins quickly find any user by name or email address across both the User Profiles and User Accounts tabs.
