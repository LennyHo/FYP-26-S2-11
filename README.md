# FYP-26-S2-11

FYP-26-S2-11 for AI Chatbot for Customer.

## PLEASE CHECK YOUR FRONTEND, BACKEND, DATABASE AND API PLATFORMS ARE WORKING ON YOUR LAPTOP BEFORE YOU START CODING.

## 
1. Frontend:  React, HTML, CSS, & JS
2. AI Platform: Dialogflow CX
3. Backend: Node.js
4. Database:

## To Run Frontend (React and Next.js):
1. run `Npm install`
2. cd Frontend
3. run `npm run dev`

## To Run BackEnd (Node.js):
1. run "npm run dev"

## Backend setup
1. Install Node.js 20 or newer.
2. Copy `.env.example` to `.env`.
3. Run `npm install`.
4. Run `npm start`.
